# Raft Lab - Fundamentals of System Security (COMSM0122)

## Workshop 4: Understanding and Stress-Testing Raft

This repository contains a simplified JavaScript-based Raft simulator designed for observing, modifying, and experimenting with the Raft consensus algorithm. The goal of this workshop is to explore how distributed systems elect leaders, replicate logs, recover from failures, and maintain consistency despite crashes, communication failures, and network partitions.

### Prerequisites
- Node.js (version 18 or newer)
- Basic familiarity with JavaScript
